# LAN Chat App

A serverless, peer-to-peer (P2P) Android messaging application that operates entirely over a local Wi-Fi network without requiring an internet connection.

## Features
- **Local Network Chat:** Message other devices on the same Wi-Fi network.
- **Peer Discovery:** Automatic device discovery using UDP broadacasting.
- **Direct Messaging:** Secure TCP-based message delivery.
- **Local Storage:** Chat history saved locally using Room Database.
- **Modern UI:** Built with Jetpack Compose.

## Tech Stack
- **Language:** Kotlin
- **UI:** Jetpack Compose
- **Database:** Room
- **Networking:** Native Socket Programming (UDP/TCP)
